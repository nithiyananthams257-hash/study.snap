# Changelog

All notable changes to the **Snap & Study** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-30

### Added
- Complete modern Streamlit UI with glassmorphism design system.
- Secure Authentication with Argon2 password hashing and session tokens.
- Subject and Document Library with multi-format ingestion (PDF, DOCX, PPTX, TXT, Images).
- Study Notes module with Beginner, Intermediate, and Exam-ready simplifications & smart summaries.
- RAG Q&A Chat with exact citations to document pages and snippet references.
- Spaced Repetition Flashcards utilizing the SM-2 scheduling algorithm.
- Interactive Quizzes with MCQs, True/False, and Short Answers with explanations.
- AI Study Planner customized for upcoming exams and target daily hours.
- Progress Analytics with study streaks, quiz performance, and weak topic alerts.
- Admin dashboard for user role administration, health monitoring, and system metrics.
- Complete FastAPI backend routers and SQLAlchemy ORM database models.
